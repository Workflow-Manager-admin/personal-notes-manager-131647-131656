# Notes Manager Frontend

A modern, minimalistic React app for personal notes management.

## Features

- User authentication (stubbed, ready for backend integration)
- Create, view, update, delete, and search notes
- Category filtering via sidebar
- Modern, lightweight layout in a light theme
- Color palette: Primary (#1976d2), Secondary (#424242), Accent (#ffc107)
- Clean, extensible components ready for REST API connection

## Layout

- Header with navigation and user session actions
- Sidebar for category filtering
- Main panel: searchable notes list, editor, and viewer

## How to Run

- `npm install`
- `npm start`

## Future Improvements

- Replace API stubs in `src/services/api.js` with real backend requests.
- Add mobile responsiveness.
- Improve error handling and offline support.
